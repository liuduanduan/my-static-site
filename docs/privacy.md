# 提交隐私说明

## 我们收集什么

工具名称、官网、产品事实用于审核；联系邮箱只用于核实本次申请。Cloudflare 提供的访问 IP 仅与站点密钥组合为不可逆限流哈希，不保存完整 IP。

## 数据如何保存

联系邮箱使用 AES-GCM 加密后存入私密 Cloudflare D1。邮箱、IP 哈希、私密查询码、合作说明和内部备注不会进入 Git 仓库、公开页面或搜索引擎。

## 保留多久

申请在终态后保留 180 天，随后删除邮箱、IP 派生值、查询码、申请内容和审核记录。系统仅保留不含个人信息的匿名数量汇总；对于已经公开收录的工具，还会保留其规范化官网域名这一公开事实，用于阻止重复申请。未完成处理的申请同样设有最长保留期限。

## 不用于营销

联系邮箱不会用于营销邮件，除非你在未来独立的授权流程中主动同意。本提交表单没有营销订阅选项。

## 查询与删除

状态查询只接受私密查询码。需要提前删除申请，请使用提交时的邮箱发送邮件至 `privacy@no996noicu.com`，并提供查询码用于核验；请勿公开发送查询码。
