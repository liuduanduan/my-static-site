# AI 工具目录站设计

## 目标

把现有休闲内容站改造成一个面向中文用户的实用 AI 工具目录。第一版以“帮助用户更快找到合适工具”为唯一核心价值，同时预留官方跳转、联盟链接、付费收录和搜索流量增长的入口。

## 产品范围

首版不做账号、社区、在线编辑器或自动爬虫。目录收录 20～30 个经过人工整理的工具，覆盖写作、图像、视频、编程、办公和音频等高频场景。

首页提供一个搜索框、分类筛选、精选工具和最近更新；工具详情页提供一句话结论、适用场景、主要能力、价格概览、优缺点、官方链接及两个替代工具。每个详情页都是可被搜索引擎独立收录的静态页面。

## 信息架构

- `/`：目录首页与搜索体验
- `/tools/<slug>`：工具详情页
- `/ai-categories/<slug>`：分类落地页
- `/about`：收录标准、更新方式与商业披露
- `/privacy`：隐私说明

保留旧内容文件和既有测试，VitePress 配置只把新的目录页面暴露到导航和构建输出中，从而确保改造可回退。

## 视觉与交互

采用高对比的深色墨蓝、温白背景和单一亮色强调，减少装饰。首页首屏只包含品牌、清晰承诺、搜索框和精选工具；卡片信息保持短句，点击卡片进入详情页。移动端采用单列布局，搜索和分类按钮始终可见。

## 数据与生成

工具数据存放在 `docs/.vitepress/theme/domain/ai-tools.json`，字段包括 slug、名称、分类、摘要、场景、能力、价格、优点、局限、官网和替代工具。Vue 组件读取同一份 JSON；Node 生成脚本根据 JSON 生成详情页和分类页，生成结果纳入 Git，保证部署时不依赖外部 API。

## 变现与合规

第一版只链接官方站点，所有商业入口使用明确的 `data-affiliate-slot` 标记，等用户提供或确认联盟链接后再启用。页面显示“价格和政策以官网为准”，不承诺收入。工具描述以人工整理为主，不批量复制官网全文；未来采集需遵守目标站点的 robots、服务条款和版权要求。

## 验收标准

1. 首页可按名称、摘要、场景和分类筛选工具，空结果有清晰提示。
2. 每个工具详情页可以独立访问、拥有唯一标题和描述，并包含官方链接。
3. 生成脚本可重复运行且输出稳定，构建产生 sitemap 和静态页面。
4. 视觉在桌面、390px 和 320px 宽度下无横向溢出。
5. 原有 Vitest 测试继续通过，并新增目录数据和搜索逻辑测试。
