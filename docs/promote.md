# 商业合作，必须比广告更透明

寻器允许工具方表达加急审核、赞助展示与联盟合作意向，但商业关系不能改变事实判断与自然排序。

## 三条不可变规则

- **付费不保证收录。** 加急费用未来只可能对应更快的处理 SLA，不对应收录承诺。
- **赞助内容明确标注。** 赞助卡片与自然目录、编辑精选分区展示，首屏标注“赞助”。
- **编辑精选不可购买。** `featuredOrder` 只由公开编辑标准决定，商业活动无权修改。

## 联盟链接

联盟动作会单独标注“联盟链接”，并与“访问官方网站”并列存在；用户始终可以选择原始官方链接。商业链接使用 `rel="sponsored"`，不会伪装成自然推荐。

## 第一阶段如何合作

当前网站只收集合作意向，不在线报价、不收款、不自动开票。报价、合同与付款在线下完成；没有有效活动时，工具页面自动回到普通官方链接。
