# 关于寻器

寻器是一个面向中文用户的 AI 工具目录。我们把分散在不同产品里的能力，按“写作、图像、视频、编程、办公、音频”等真实场景整理在一起，帮助你少花时间比较，多花时间完成事情。

## 我们怎么收录

- 优先收录有明确用途、可以直接访问的产品。
- 每个工具都用简短的人话说明“适合谁”和“能解决什么问题”。
- 页面由人工整理，价格与功能会随官网变化，使用前请以官方信息为准。
- 当前目录只放官方链接，不代替工具方做安全、版权或效果保证。

## 商业说明

寻器不做隐藏推广。赞助内容和联盟链接必须明确标注并与编辑精选分开；商业关系不会改变工具的收录标准、自然排序或替代关系。完整规则见[商业合作与披露](/promote)。

## 更新建议

如果你发现工具信息过期，或想推荐一个适合中文用户的工具，可以直接使用[工具提交页](/submit)。普通收录永久免费，提交不保证收录；每项申请都由人工核对。
